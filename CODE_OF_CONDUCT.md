# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**.

The full text is published at:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

To report a concern, contact the maintainer listed in `pyproject.toml`. Reports will be reviewed promptly and kept confidential.

By participating in this project — opening issues, submitting PRs, or commenting in discussions — you agree to abide by the linked Code of Conduct.
