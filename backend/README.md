# RA3 Inventory backend

Python backend for the RA3 Inventory desktop application. It provides a local API
for browsing and exporting Lutron RadioRA 3 inventory through LEAP.

See the [project README](https://github.com/Vasilis/lutron-ra3-inventory#readme)
for setup, usage, architecture and security guidance. This package contains
application code and test fixtures; it does not include paired
credentials or a user's saved inventory.
